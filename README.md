# Staff Data Analysis using Excel

## 📊 Project Overview

This project analyzes employee/staff data using Microsoft Excel to identify workforce patterns, salary trends, employee distribution, and hiring trends.

The project follows an end-to-end data analytics workflow:

**Data Import → Data Cleaning → Data Transformation → Analysis → Visualization → Dashboard → Business Insights**

The main objective is to transform raw staff data into meaningful information that can support workforce-related decision making.

## 🔄 Data Analytics Workflow

### 1. Data Import

The staff dataset was imported into Microsoft Excel.

### 2. Data Cleaning & Transformation

Power Query was used to clean and transform the raw dataset.

The transformation process included:

- Cleaning the imported data
- Extracting and transforming required fields
- Renaming columns
- Standardizing values
- Replacing required values
- Preparing the dataset for analysis

### 3. Pivot Table Analysis

Pivot Tables were created to analyze:

- Employees by Department
- Average Salary by Department
- Employees by Employee Type
- Employees by Work Location
- Gender Distribution
- Hiring Trends

### 4. Data Visualization

Pivot Charts were created to communicate the analysis through:

- Bar Charts
- Column Charts
- Doughnut Charts
- Line Charts

### 5. Interactive Dashboard

An interactive Excel dashboard was created using:

- KPI cards
- Charts
- Slicers
- Pivot Tables
- Pivot Charts

The dashboard allows users to filter the analysis based on relevant employee attributes.

## 📈 Analysis Performed
